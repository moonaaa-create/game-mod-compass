# Game Compass (게임 나침반)

사용자의 취향과 플레이 상황을 반영해 **지금 나에게 맞는 게임과 게임 모드**를 추천하는 AI 서비스입니다.

## 문제 정의

게임/모드 선택지는 많지만, 인기순 추천만으로는 개인 취향과 현재 상황(혼자/친구와, 짧은 시간/긴 시간, 경쟁/힐링 등)을 충분히 반영하기 어렵습니다.

## 핵심 기능 (MVP)

1. **취향 기반 맞춤 추천**: 간단한 질문 응답을 통해 선호 성향 파악
2. **상황 반영 추천**: 현재 플레이 상황(시간, 인원, 난이도 선호 등) 입력 반영
3. **추천 이유 설명**: 왜 이 게임/모드가 맞는지 AI가 이해 가능한 문장으로 설명

## 추천 시스템 접근 방식

- **후보 추출**: 태그 기반 필터링/매칭(장르, 난이도, 플레이 시간, 멀티 여부, 분위기 등)
- **설명 생성**: LLM을 이용해 개인화된 추천 이유 생성
- **핵심 구조**: `질문 응답 + 태그 매칭 + LLM 설명`

## MVP TODO

### Phase 1. Taxonomy & data

- 게임/모드 분류 체계 정의: 장르, 난이도, 플레이 시간, 인원, 분위기, 숙련도
- 추천에 필요한 공통 태그 스키마 설계
- 초기 데이터셋(CSV/JSON) 수집 및 샘플 1차 정리
- 게임과 모드가 같은 기준으로 비교되도록 메타데이터 정규화

### Phase 2. Recommendation logic

- 질문 응답으로 사용자 선호와 현재 상황을 수집하는 흐름 설계
- 태그 매칭 점수로 후보를 추출하는 기본 추천 규칙 구현
- 추천 결과에 우선순위와 제외 조건을 반영
- 각 추천에 한 줄짜리 근거를 생성하는 LLM 프롬프트 초안 작성

### Phase 3. MVP product flow

- 추천 입력 → 결과 → 이유 설명까지 이어지는 단일 화면 구성
- 결과를 재추천할 수 있는 최소한의 수정/재입력 흐름 추가
- 추천 저장 또는 복사 같은 가벼운 후속 행동 추가

### Phase 4. Validation

- 실제 사용자 시나리오 5~10개로 추천 품질 점검
- 잘못 분류된 항목을 기준으로 태그/가중치 보정
- MVP 범위에 맞는 데이터 부족 항목을 우선순위로 정리

## 기술 스택 (제안)

- **Frontend**: React + TypeScript + Vite (또는 Streamlit)
- **Backend**: FastAPI (Python)
- **Data**: CSV/JSON 기반 게임·모드 메타데이터, PostgreSQL(초기 MVP는 SQLite 가능)
- **AI**: OpenAI API(또는 동급 LLM API)
- **(선택) 검색 고도화**: pgvector 또는 FAISS
- **Deployment**: Vercel(Frontend), Render/Railway(Backend)
