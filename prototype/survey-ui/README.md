# PROTOTYPE — 취향 설문 UI (throwaway)

이슈 [#9 취향 설문 UI 프로토타입](https://github.com/moonaaa-create/game-mod-compass/issues/9)를 위한 throwaway 프로토타입입니다.
프로덕션 코드가 아니며, 결정이 확정되면 이 브랜치(`prototype/survey-ui`)만 남기고 main에는 합쳐지지 않습니다.

## 실행 방법

빌드 없이 바로 브라우저로 엽니다:

```bash
open prototype/survey-ui/index.html
```

또는 `index.html`을 더블클릭하세요.

## 변형 (Variants)

`?variant=A|B|C` 쿼리 파라미터로 전환하거나, 화면 하단 플로팅 바의 좌우 화살표(또는 키보드 ←/→)로 전환합니다.

- **A — 스텝 마법사형**: 중앙 카드 하나에 진행률 바 + 질문 1개씩, "다음/이전"으로 이동.
- **B — 사이드바 + 그리드 대시보드형**: 좌측 사이드바에 3단계 진행 표시, 우측 메인에 큰 타일형 선택지.
- **C — 대화형 챗봇 스타일**: 말풍선으로 질문이 쌓이고, 답변도 채팅처럼 표시. 결과도 채팅 리스트로 표시.

모든 변형은 동일한 흐름을 다룹니다: 게임 선택(로블록스/마인크래프트) → 맞춤 설문(#7에서 확정된 문항) → 상위 5개 추천 결과.

## 데이터

설문 문항과 추천 결과는 모두 인메모리 mock 데이터입니다 (이슈 #7, #8의 결정 반영). 실제 API/DB 연동 없음.
