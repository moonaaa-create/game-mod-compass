Problem

왜 이 서비스가 필요할까요?

😵‍💫 선택지가 너무 많다

로블록스에는 수백만 개의 게임이, CurseForge에는 수만 개의 마인크래프트 모드가 있습니다. 무엇부터 해야 할지 막막합니다.

🔍 검색은 성향을 모른다

키워드 검색은 인기순/이름순 나열일 뿐, "친구랑 하기 좋은 게임"처럼 상황에 맞는 추천을 해주지 않습니다.

💬 편하게 물어보고 싶다

메뉴를 클릭하며 필터를 맞추는 대신, 사람에게 물어보듯 자연스럽게 대화하며 추천받고 싶습니다.

Solution

취향을 말하면, AI가 골라줍니다

Game Compass는 사용자의 성향과 취향을 분석해 최적의 마인크래프트 모드와 로블록스 게임을 추천해주는 대화형 AI 서비스입니다. 회원가입 없이, 무료로, 채팅하듯 이용할 수 있습니다.

누구를 위한 서비스인가요?

🎮 신규/라이트 유저

로블록스나 마인크래프트를 처음 접하거나, 오랜만에 다시 시작하려는 사용자. 무엇부터 해야 할지 몰라 고민하는 분들.

👥 친구와 함께하고 싶은 유저

"친구들이랑 다 같이 할 수 있는 게임", "혼자 편하게 즐길 콘텐츠"처럼 상황별 맞춤 추천이 필요한 사용자.

공통점: 별도 계정 없이, 부담 없이 바로 추천을 받아보고 싶은 모든 사람.

Core Feature 1 / 3

🟥 로블록스 인기 상위 94개 게임

로블록스 공식 API(games.roblox.com)로 조회한 실제 인기 게임 94종의 장르, 동시접속자 수, 누적 방문 수, 최대 인원 데이터를 기반으로 취향에 맞는 게임을 추천합니다.

추천 기준

  • 선호 장르: 어드벤처 / 시뮬레이터 / 롤플레이 / 오비(장애물) 등
  • 인원 선호: 친구들과 대규모 멀티 vs 혼자/소규모 캐주얼
  • 실제 동접자 수·인기도 기반 정렬로 상위 5개 최종 제시
Core Feature 2 / 3

🟩 CurseForge 상위 100개 모드

세계적인 모드 플랫폼 CurseForge에서 엄선된 인기 상위 100가지 마인크래프트 모드 데이터를 기반으로, 건축·모험·공학 등 사용자의 성향에 맞는 최적의 모드를 추천합니다.

추천 카테고리 (4종)

  • 🛠️ 기술(Technology) — 자동화·공학 계열
  • 🪄 마법(Magic) — 마법·주문 계열
  • 🗺️ 모험/RPG(Adventure and RPG) — 탐험·전투 계열
  • 📍 지도/정보(Map and Information) — 좌표·정보 표시 계열

모드로더(Forge/Fabric/NeoForge)는 구분 없이 통합 인기순, 결과 카드에 태그로만 표시됩니다.

Core Feature 3 / 3

🤖 쉬운 대화형 AI 가이드

Process

💬 어떻게 만들었나요?

1

Wayfinder 방식 인터뷰로 스펙 확정

Copilot CLI + Matt Pocock/Wayfinder 방식의 대화형 프롬프트 인터뷰로 세부 요구사항을 GitHub 이슈(#1~#13)로 정리, docs/spec.md로 확정.

2

MVP 풀스택 구현

SQLModel 데이터 모델 → FastAPI 라우터 → Vue 챗봇형 UI까지 백엔드/프론트엔드 전 영역을 한 번에 구축, 로컬 E2E 검증.

3

Fleet 모드 — 병렬 에이전트 작업

실제 Roblox universe ID 59개 확보, CurseForge 카테고리 매핑, Render 배포 설정을 3개 백그라운드 에이전트로 동시 진행.

4

자유 대화형 AI + 디자인 통합

칩 클릭식 UI를 자유 텍스트 채팅으로 전환하고, 팀원이 제작한 랜딩/채팅 디자인을 Vue 컴포넌트로 이식.

📱 데모 시나리오

1️⃣ 홈 화면

서비스 소개, 기능 카드(픽셀아트), 기술 스펙 아코디언, 팀 소개를 훑어봅니다.

2️⃣ "AI 대화 시작" 클릭

네브바 또는 히어로 버튼으로 채팅 화면(플로팅 네브바 + 글래스 카드)으로 전환합니다.

3️⃣ 자연스러운 대화

"친구들이랑 하기 좋은 로블록스 게임 알려줘"처럼 자유롭게 입력하면 AI가 후속 질문을 이어갑니다.

4️⃣ 추천 결과 확인

썸네일·동접자 수·태그가 포함된 추천 5개를 확인하고, "새로 추천받기"로 재시작합니다.
